# ANGELA v19 — Admin Console Integration

## Implemented
- Admin Console connects to the Backend using `X-Admin-Key`.
- Withdrawal queue loads from `GET /api/admin/withdrawals`.
- Pending withdrawals can be approved or rejected.
- Processing withdrawals can be completed with a real `0x` 32-byte transaction hash or rejected.
- No transaction hash is generated by the UI.
- Admin key is kept in `sessionStorage` only.

## Launch safety
The existing server-side `WITHDRAWALS_ENABLED` launch lock remains authoritative. Admin actions do not bypass it for user requests.

## Production requirement
Do not expose `ADMIN_API_KEY` in frontend source, public repositories, or static build artifacts. For production, serve the Admin Console from a protected origin and use HTTPS.
